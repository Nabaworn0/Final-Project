# โครงสร้างโครงการ CED Teaching Assessment

โครงการจัดแบบ **feature-based** เพื่อให้หาไฟล์จากงานที่กำลังพัฒนาได้ง่าย และแยกหน้าเว็บออกจากโค้ดฝั่งเซิร์ฟเวอร์อย่างชัดเจน

```text
AI-Teaching-Assessment/
├─ app/                         # URL และหน้าที่ผู้ใช้เปิด
│  ├─ api/                     # จุดรับข้อมูลจากฟอร์ม
│  ├─ instructor/              # เส้นทางฝั่งอาจารย์ (พัฒนาระยะถัดไป)
│  ├─ login/                   # หน้าเข้าสู่ระบบ
│  └─ student/                 # เส้นทางฝั่งนักศึกษา
├─ features/                    # หน้าตาและองค์ประกอบ แยกตามผู้ใช้/งาน
│  ├─ instructor/              # Shell, Dashboard และแบบประเมินของอาจารย์
│  └─ student/
│     ├─ components/           # โครงหน้าที่ใช้ร่วมกันในฝั่งนักศึกษา
│     └─ lesson-plans/         # ส่วนอัปโหลดและแสดงแผนการสอน
├─ lib/
│  ├─ analysis/                # อ่านเอกสารและตรรกะวิเคราะห์
│  └─ server/                  # ยืนยันตัวตนและติดต่อฐานข้อมูล/ที่เก็บไฟล์
├─ db/                          # โครงสร้างฐานข้อมูล
├─ drizzle/                     # ประวัติการเปลี่ยนแปลงฐานข้อมูล
├─ public/                      # โลโก้และไฟล์สาธารณะ
├─ tests/                       # การทดสอบอัตโนมัติ
└─ docs/                        # เอกสารสำหรับทีมพัฒนา
```

## กติกาการวางไฟล์

1. `app/**/page.tsx` ควรสั้น ทำหน้าที่รับข้อมูลและเรียกคอมโพเนนต์จาก `features/`
2. ส่วนแสดงผลของฟีเจอร์ใหม่ให้อยู่ใน `features/<ผู้ใช้>/<ชื่อฟีเจอร์>/`
3. โค้ดที่แตะฐานข้อมูล คุกกี้ หรือไฟล์อัปโหลดให้อยู่ใน `lib/server/`
4. โค้ดแปลงเอกสาร ถอดเสียง หรือเปรียบเทียบเนื้อหาให้อยู่ใน `lib/analysis/`
5. ใช้ path แบบ `@/...` สำหรับ import ภายในโครงการ เพื่อลด `../../../` และย้ายไฟล์ได้ง่าย

## จุดที่ควรพัฒนาต่อ

เมื่อเริ่มระบบคลิปฝึกสอน ให้สร้าง `features/student/practice-sessions/` สำหรับหน้าตาและชนิดข้อมูล และสร้าง API ใต้ `app/api/student/practice-sessions/` จากนั้นแยกบริการเก็บคลิป/ผลเปรียบเทียบไว้ใน `lib/server/` กับ `lib/analysis/` ตามหน้าที่

ฝั่งอาจารย์เริ่มพัฒนาแล้วใน `features/instructor/dashboard/` และ `features/instructor/evaluations/` โดยแบบประเมินรอบแรกคำนวณคะแนนเฉลี่ยบนหน้าเว็บ ส่วนการบันทึกลงฐานข้อมูลเป็นงานลำดับถัดไป
